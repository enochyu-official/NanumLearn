# Nanum Learn

[Nanum Learn](https://nanumlearn.enochyu.com/) is an educational
initiative that aims to accelerate open learning by providing original
and accessible resources such as books, handouts, and free classes.
We aim to make the contents and resources more accessible by
distributing the works under CC BY 4.0. Under the permissive license,
the users are allowed to share and adapt for any purpose as long as
appropriate credits are given. For more information the use,
please visit [LICENSE]().

## Mission Statement
    To inspire global learners by returning knowledge and skills we have received.
